# Raw data

The raw CSV files are not redistributed here. Download them from their original
public sources and place them in this folder with exactly these names.

| File | Content |
|---|---|
| `Global Dataset of Inflation.csv` | Global inflation (headline Consumer Price Inflation is used) |
| `Raw_WIDER_data.csv` | WIDER income and inequality data |
| `WDI_GINI_data.csv` | World Development Indicators Gini data |
| `peace_index.csv` | Global Peace Index (semicolon separated, decimal commas) |

Source links (add the exact Kaggle or publisher URL of each file before publishing)
- Global inflation (https://www.kaggle.com/datasets/sazidthe1/global-inflation-data)
- WIDER income and inequality (https://www.kaggle.com/datasets/mannmann2/world-income-inequality-database)
- WDI Gini (https://www.kaggle.com/datasets/ulrikthygepedersen/gini-index-per-country)
- Global Peace Index (https://www.kaggle.com/datasets/natalyreguerin/global-peace-index-gpi)

The Python pipeline also accepts `Global_Dataset_of_Inflation.csv` (with underscores).
The Pentaho jobs expect the name with spaces shown above.
